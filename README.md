# SmartShop
A smart shopping system developed in Java as part of university coursework

Instructions For Usage : 

Inventory Features:
  - Adding a product:
    - Navigate to the Inventory tab, click the "Add Product" button, fill in the text areas as required, click submit
  - Removing a Product:
    - Navigate to the Inventory tab, click the "Remove Product" button, fill in the product name, click submit
  - Editing a Product:
    - Navigate to the Inventory tab, click the "Edit Product" button, fill in the information as necessary, click submit
  - Generating an Inventory Report:
    - Navigate to the Inventory tab, click the "Generate Report" button, read and close the feedback box, open the InventoryReport.csv file in your file system

Sales Features:
  - Add a sale:
    - Navigate to the sales menu, click "Add Sale", input the necessary information into the popup window, click submit
  - Undo last sale:
    - navigate to the sales menu, click the "Undo Last Sale" button, read the feedback form and close it, the laast sale has been removed
  - Generating an Sales Report:
    - Navigate to the Sales tab, click the "Generate Report" button, read and close the feedback box, open the SalesReport.csv file in your file system
